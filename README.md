# AppGalaxy 🌌

A modern, clean, minimalist, and fully responsive **All-in-One Apps Hub** built with pure HTML, CSS, and vanilla JavaScript.

![AppGalaxy Preview](https://raw.githubusercontent.com/shishantchabbira-stack/App-Galaxy/main/preview.png)

## ✨ Features

- **115+ Popular Apps & Web Services**: Complete coverage across 7 categories:
  - 🌐 **Social Media**: TikTok, Facebook, Instagram, WhatsApp, X, Telegram, Reddit, LinkedIn, Discord, etc.
  - 🎬 **Entertainment**: YouTube, Netflix, Spotify, Disney+, Prime Video, Twitch, Crunchyroll, etc.
  - 🤖 **AI Tools**: ChatGPT, Google Gemini, Claude AI, Midjourney, Copilot, Perplexity, DeepSeek, etc.
  - 💼 **Productivity**: Google, Canva, Notion, Gmail, Google Drive, Microsoft 365, Figma, Zoom, Slack, etc.
  - 🎓 **Education**: Duolingo, Coursera, Khan Academy, Udemy, Wikipedia, Codecademy, etc.
  - 🎮 **Gaming**: Steam, Roblox, Epic Games, PlayStation, Xbox, Chess.com, etc.
  - 🛍️ **Shopping**: Amazon, eBay, AliExpress, Walmart, Etsy, Temu, SHEIN, etc.
- **Direct Official Web Links**: Instantly launch official web versions with a single click.
- **Official Platform Downloads Modal**: Get verified download links for Android (Google Play), iOS (App Store), and PC (Microsoft Store / Desktop).
- **Fast Live Search & Quick Filter Chips**: Instant fuzzy search across apps, taglines, and descriptions.
- **Category Filter Bar**: Smooth scrolling pill tabs with live category counts.
- **Trending Section**: Showcases the most popular daily tools and platforms.
- **Dark / Light Mode**: Beautiful modern theme toggle with preference saved in `localStorage`.
- **Responsive Design**: Looks great on smartphones, tablets, laptops, and ultra-wide desktop monitors.
- **News Section Placeholder**: Prepared for upcoming curated industry updates and releases.

## 📁 Project Structure

```
App-Galaxy/
├── index.html       # Semantic HTML5 hub structure, modal, news & footer
├── style.css        # Responsive CSS design system with light/dark variables
├── data.js          # Master catalog of 115+ apps, icons, and official links
├── app.js           # Core interactive logic (search, category filter, modal, favorites)
└── README.md        # Documentation and overview
```

## 🚀 Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/shishantchabbira-stack/App-Galaxy.git
   ```
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
3. No build tools or installations required—100% vanilla web technology.
